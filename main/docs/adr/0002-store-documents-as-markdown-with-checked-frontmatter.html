Store documents as Markdown with checked frontmatter

Replaces ADR-0001: documents carry checked frontmatter.

On this page

  • Context
  • Decision
  • Consequences

Context

Markdown alone (ADR-0001) does not give the documents a schema.

Decision

Documents are Markdown with YAML frontmatter that the validator checks (ADR-0001), on the approved runtime (TECH-0001).

Consequences

The validate check fails documents with bad frontmatter.
